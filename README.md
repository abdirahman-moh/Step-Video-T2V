# Modern Web Sayfası

Bu proje, modern web teknolojileri kullanılarak geliştirilmiş responsive ve interaktif bir web sayfasıdır.

## 🚀 Özellikler

- **Responsive Tasarım**: Tüm cihazlarda mükemmel görünüm
- **Modern UI/UX**: Güncel tasarım trendleri
- **Smooth Animations**: CSS ve JavaScript animasyonları
- **Interactive Elements**: Hover efektleri ve geçişler
- **Contact Form**: Çalışan iletişim formu
- **Mobile Menu**: Mobil cihazlar için hamburger menü
- **SEO Friendly**: Arama motoru optimizasyonu

## 🛠️ Teknolojiler

- **HTML5**: Semantic markup
- **CSS3**: Modern styling ve animasyonlar
- **JavaScript (ES6+)**: Interaktif özellikler
- **Font Awesome**: İkonlar
- **Google Fonts**: Typography

## 🚀 Kurulum

1. Dosyaları bilgisayarınıza indirin
2. `index.html` dosyasını web tarayıcınızda açın
3. Veya bir local server kullanın:

```bash
# Python ile
python -m http.server 8000

# Node.js ile
npx serve .

# PHP ile
php -S localhost:8000
```

## 📝 Kullanım

### HTML Yapısı
```html
<!DOCTYPE html>
<html lang="tr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Modern Web Sayfası</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <!-- Navigation -->
    <nav class="navbar">
        <!-- Navbar content -->
    </nav>

    <!-- Hero Section -->
    <section id="home" class="hero">
        <!-- Hero content -->
    </section>

    <!-- Other sections... -->
</body>
</html>
```

### CSS Sınıfları
```css
/* Buttons */
.btn-primary
.btn-secondary

/* Sections */
.hero
.about
.services
.contact

/* Cards */
.service-card
.stat
.contact-item
```

### JavaScript Fonksiyonları
```javascript
// Form validation
isValidEmail(email)

// Notifications
showNotification(message, type)

// Counter animation
animateCounter(element, target)
```

## 🔧 Özelleştirme

### Renkleri Değiştirme
`style.css` dosyasında CSS değişkenlerini kullanabilirsiniz:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #667eea;
    --accent-color: #fbbf24;
}
```

### İçerik Güncelleme
- `index.html` dosyasında metinleri değiştirin
- İkonları Font Awesome'dan seçin
- Resimleri kendi resimlerinizle değiştirin

### Yeni Bölüm Ekleme
1. HTML'de yeni section oluşturun
2. CSS'de stilleri ekleyin
3. JavaScript'te gerekli fonksiyonları ekleyin
